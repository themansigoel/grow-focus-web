## 🌟 Key Features & Architecture
- **3D Living Botanical Sanctuary**: Built with SpriteKit & Metal shaders, featuring 7 thematic isometric island biomes and ambient fauna.
- **10 Neuropsychology Attention Gyms**: Sustained attention (Hold Focus), impulse control (Don't Tap), working memory (Remember & Act), task switching (Rule Switch), and vagal breathing.
- **Anti-Wilt Pomodoro Stakes**: Background transitions $\ge 10$ seconds immediately terminate sessions and wilt the active plant.
- **Apple HealthKit Sync**: Mindful Sessions logged automatically to Apple Health.
- **Multi-Storefront Indexing**: Complete localized pages for 10 languages (`en`, `de`, `ja`, `zh-Hans`, `zh-Hant`, `ko`, `fr`, `es`, `it`, `pt-BR`).
- **SEO / GEO / AEO**: Pre-structured JSON-LD `SoftwareApplication` and `FAQPage` schemas, `sitemap.xml`, `robots.txt`, and `llms.txt`.
